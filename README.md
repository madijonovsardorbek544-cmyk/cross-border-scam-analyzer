# Cross-Border Scam Analyzer (CBSA)

CBSA is a student-led cybersecurity project that analyzes how online scams
adapt across countries, languages, and social contexts.

The project combines:
- Cybersecurity awareness
- Psychological analysis of scams
- Cross-border and international relations perspectives

## What This Project Does
CBSA collects real scam examples and analyzes:
- Who is targeted
- Which psychological tactics are used
- How language is simplified or manipulated
- How the same scam changes across regions

## Case Studies
- Case 001: Fake Account Message  
  (Cross-border psychological and linguistic analysis)

## Impact
This project aims to improve digital safety by helping users recognize
common scam patterns before harm occurs. It is designed for educational
and preventive purposes.

## Ethics
CBSA does not collect personal data and focuses on awareness, transparency,
and responsible cybersecurity practices.
